## 🟦 Betaflight Contributions

### 🔍 Global Settings Search — [PR #5555](https://github.com/betaflight/betaflight-configurator/pull/5555)

*Open · Milestone 2026.12*

Adds a global settings search to Betaflight Configurator.

- Search settings across all visible tabs, ranked by relevance
- Tab and section breadcrumbs in the results
- Jumps straight to the selected setting and highlights it
- Respects tab visibility and Expert Mode
- Opens with **Ctrl/Cmd + K** (works with English and Arabic keyboard layouts)
- Fully localized UI

### 🎛️ AUX Channel Usage in Receiver Tab — [PR #5535](https://github.com/betaflight/betaflight-configurator/pull/5535)

*Merged · Milestone 2026.12*

Gives AUX channels clear visual states based on their mode ranges, making channel activity easier to understand and troubleshoot:

- Unused → gray
- Assigned to a mode → cyan
- Currently inside an active range → bright cyan with a glow
